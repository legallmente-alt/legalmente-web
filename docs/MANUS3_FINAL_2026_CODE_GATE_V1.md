# MANUS3_FINAL_2026_CODE_GATE_V1

**Producto:** LegalMente  
**Dirección:** The Editorial Instrument  
**Estado:** Contrato aprobado para implementación aislada; no merge, no deploy y no publicación.  
**Rama:** `feat/legalmente-editorial-instrument-preview-v1`

## Propósito

Este contrato traduce el gate visual Manus 3, el red-team de Manus 2-R y los proofs ganadores en reglas implementables por superficie. La dirección aprobada no autoriza a conservar el scaffold actual como producto final: autoriza únicamente la reconstrucción aislada de Home Desktop y Home 390 como primer corte, seguida por la validación de 360 y 430 y la extensión al resto de las superficies.

La regla compositiva no negociable es **una acción enfocada, un evento visual memorable y una razón visible para continuar**. La arquitectura de producto, la lógica jurídica, las fuentes, el territorio, los límites y el copy deben permanecer separados de los archivos de imagen. El arte puede orientar, sugerir y crear continuidad, pero no puede contener claims jurídicos no aprobados, fechas, importes, URLs, PII ni jurisdicciones.

## Reglas transversales

| Área | Contrato |
|---|---|
| **Assets** | Los 20 assets permanecen como biblioteca selectiva. Se conservan los veredictos Manus 2-R: `KEEP`, `KEEP_WITH_CROP` y `SPECIALIZED_ONLY`; no se regenera la biblioteca sin una ambigüedad de producto demostrada. El manifest debe mantener focal point, safe area, crop, superficie y disponibilidad binaria. |
| **Symbols** | Learn, Resolve, Prepare, Source, Contract y Evidence son fuertes; Case, Territory, Compare, Alert y Labor son contextuales; Company requiere rework. Ningún símbolo va por defecto en una fila de badges circulares. |
| **Copy y datos** | Legal copy, fuentes, territorio, limits, fechas, importes, URLs, PII y jurisdicciones son UI/data-bound. Las imágenes solo pueden contener pseudotexto aprobado y no pueden ser la única fuente de comprensión. |
| **Motion** | Toda transición comunica jerarquía o causalidad, dura poco, se puede cancelar y ofrece equivalencia estática. Prohibidos autoplay parallax, bounce, looping pulse, generic zoom y significado motion-only. |
| **Responsive** | 360, 390 y 430 son composiciones deliberadas. El ancho adicional en 430 se usa para negative space, no para añadir módulos. Ningún titular debe recortarse con texto grande o zoom del navegador. |
| **Fail-closed** | Los estados no resueltos deben permanecer visibles y conservadores. `HOLD`, `OUT_OF_SCOPE` y `REVIEW_REQUIRED` son salidas válidas, no errores que se oculten visualmente. |
| **Release** | Esta rama continúa aislada. No se permite merge, deploy, publicación ni sustitución del root público hasta que existan los proofs de implementación y el siguiente gate explícito. |

## Secuencia de implementación

Primero se implementan Home Desktop y Home 390 con W01/W02/W03 y la navegación contextual. Después se prueban 360 y 430 sin añadir módulos. A continuación se montan las composiciones de Discovery, Series, Tool, Trust, Cinema & Law y Evidence, reutilizando datos y lógica pero no el mismo shell visual. Finalmente se incorpora motion causal, reduced motion, source/territory/limits data-bound y la batería de aceptación anterior.

## Gate de salida

El contrato se considera cumplido solo cuando los proofs de implementación reproducen la jerarquía del arte aprobado, las superficies permanecen diferenciadas, los assets sobreviven a los crops, la utilidad es evidente, la confianza es accesible y el comportamiento reducido conserva significado. Incluso entonces, este contrato no autoriza por sí mismo merge, deploy o publicación; requiere un gate posterior y explícito.

**Resultado del contrato:** `ART_PASS_FOR_ISOLATED_IMPLEMENTATION` para comenzar Home Desktop + Home 390 en la rama aislada; el scaffold actual no queda aprobado como UI pública.
